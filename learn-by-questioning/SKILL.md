# Learn by Questioning（陌生领域提问学习法）

用结构化的**提问思维框架**代替死记硬背与术语轰炸，帮助学习者打破“不知道自己不知道”的盲区，从零搭建知识骨架并逐层穿透本质。

## 核心原则（底层思维切换）

在回答或引导用户学习任何陌生知识点 **X** 时，始终贯彻三个思维切换：
1. **从“求全”切换到“锚定”**：绝不一开始就堆砌百科式术语定义；优先用用户熟悉的日常事物或已知领域做类比。
2. **从“被动接收”切换到“逆向拆解”**：先讲清楚“它为解决什么痛点而生、没有它会怎样”，再讲它是什么。
3. **从“怕问蠢问题”切换到“假设驱动（抛砖引玉）”**：鼓励用户抛出粗糙猜想，通过纠错和边界对比拉高信息密度。

## 步骤 1：判断学习阶段与模式

根据用户的输入和目标，自动选择最合适的模式（若用户未明确指定，默认从 **模式 A：快速破冰** 开始，并在结尾提供进入模式 B / C 的引导）：

| 模式 | 适用场景 | 核心方法组合 |
| :--- | :--- | :--- |
| **模式 A：快速破冰** | 零基础、刚听说一个新名词/新领域，10 分钟搭出认知骨架 | 万能 6 问 + 5W1H 宏观地图 + 费曼锚定 |
| **模式 B：深度穿透** | 知道大概概念但觉得“浮在表面”或被行业黑话绕晕，想吃透底层逻辑 | 第一性原理 + 5 Whys + 伯格三步曲（Why→What if→How）+ 逆向边界 |
| **模式 C：互动反考** | 用户想检验自己是否真懂、想通过对话练手或纠正模糊认知 | 费曼复述 + 假设纠错 + 苏格拉底追问 + 布鲁姆认知阶梯 |

> 如需查阅完整的方法论词典、学科专属视角（理工/社科/商业）或经典书籍对照，按需读取 [frameworks.md](./references/frameworks.md)。

## 步骤 2：按模式执行

### 模式 A：快速破冰（万能 6 问骨架）

严格按以下 **4 个阶段、6 个核心问题** 输出结构化拆解，控制语言通俗、克制术语：

1. **定坐标（看痛点）**
   - **Q1**：X 是为了解决什么具体痛点而诞生的？在它出现之前，大家是怎么凑合解决的？
2. **找锚点（降维理解）**
   - **Q2**：如果用生活中的常见事物来打比方，X 最像什么？（明确指出类比成立的地方，以及类比失效的地方）
   - **Q3**：去掉所有修饰和黑话，X 最核心的运作机制用 1–2 句话怎么概括？
3. **划边界（防混淆）**
   - **Q4**：X 和最容易混淆的相似概念 Y（自动挑选 1–2 个）最本质的区别是什么？
   - **Q5**：X 有什么局限性？在什么场景下会失效或绝对不该用它？
4. **落实践（找抓手）**
   - **Q6**：给出 1 个最简单具体的现实案例；并列出如果用户想继续入门，最核心、必须先弄懂的 **前 3 个子概念**。

*若用户要学习的不是单个概念而是一个**庞大行业/学科**，在定坐标前先用 **5W1H**（What/Who/Where/When/Why/How）用 6 行以内画出宏观知识地图。*

---

### 模式 B：深度穿透（剥离黑话与挖根因）

针对用户卡住或想深挖的知识点，按四步穿透：

1. **第一性原理去噪**：区分哪些是该领域不可再分的**底层公理/物理或逻辑约束**，哪些只是**行业惯例、历史包袱或营销包装**。
2. **5 Whys 因果深挖**：围绕核心机制或现象连续追问 3–5 层“为什么”，直到触及底层规律、成本结构或人性/制度驱动力。
3. **伯格三步曲推演**：
   - *Why*：为什么现有方案长这样？
   - *What if*：如果改变其中一个关键前提或约束，整个系统会发生什么变化？
   - *How*：底层究竟是如何工程化/现实落地的？
4. **逆向思维与双环压力测试**：
   - *逆向（Inversion）*：“如果想让 X 彻底失败或产生最坏结果，需要哪些条件？”
   - *双环审视（Double-Loop）*：“理解 X 时，新手最容易带入哪个错误的旧心智模型？”

---

### 模式 C：互动反考（费曼 + 布鲁姆 + 苏格拉底）

采用**多轮对话**而非一次性长篇大论，每次只推进 1 个小步：

1. **启动**：请用户用自己的大白话复述对 X 的理解，或者直接抛出一个“粗糙猜想”（如：“我猜 X 就是升级版的 Y，对吗？”）。
2. **定位盲区**：肯定说对的部分，精准指出解释中**卡顿、偷换概念或依赖黑话**的那一处。
3. **苏格拉底追问（每次只问 1–2 个问题）**：沿布鲁姆认知阶梯逐步拉升：
   - *理解层*：“你刚才提到 [某词]，如果不能用这个专业词，你会怎么描述？”
   - *应用层*：“如果把你说的规则放到 [具体新场景] 里，还会成立吗？”
   - *分析/评价层*：“这个结论背后默认了什么前提？如果有反例会怎样？”
   - *创造层*：“结合你原本熟悉的领域，你能用 X 解决什么问题？”
4. **阶段复盘**：每 2–3 轮总结一次用户已经修正并掌握的认知，避免迷失。

---

## 步骤 3：收尾与下一步引导

每次完成模式 A 或模式 B 后，必须给出 **2–3 个可直接点击/复制的进阶追问方向**，帮助用户把“知识骨架”继续长出枝叶，例如：
- 深入拆解前 3 个子概念中的某一个；
- 切换到 **模式 B（深度穿透）** 或 **模式 C（费曼反考）** 检验理解；
- 如用户需要整理向专家请教或阅读论文的问题清单，可建议配合使用 `question-craft` 技能。
