# Design Review Checklist

- Is the agent shape classified correctly?
- Does every subsystem correspond to a real requirement?
- Is the loop explicit and understandable?
- Are tools grouped by risk and side effects?
- Is memory scoped by retention horizon?
- Is gateway usage justified?
- Is multi-agent usage justified?
- Are recovery and restart rules defined?
- Are eval tasks realistic?
- Can the first version be made simpler?
