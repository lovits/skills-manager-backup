# Core Intake

## Goal

Get enough facts to classify the harness well before any branch decision.

## Ask First

1. What does the agent actually do?
2. Who uses it, and in what moment?
3. How much action should it take on its own?
4. What counts as success, and what counts as failure?
5. If still unclear: where does it live and operate
   (`local CLI`, `editor`, `chat channel`, `gateway`, `background`, or
   `shared core`)?

## Rules

- Ask one question at a time.
- Prefer plain language over harness jargon.
- Do not open `memory`, `gateway`, `delegation`, or `provider` branches yet.
- If the user gives features instead of a job, push back and restate the job.
- Do not stop after one answer if the 4 core facts are still incomplete.
