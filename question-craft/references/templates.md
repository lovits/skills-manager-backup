# 高质量提问模板与改写对照库

本参考文件供 `question-craft` 按需查阅，提供常见场景的“差问题 vs 好问题”改写示范与即用型问题模板。

---

## 一、问题升级改写对照表（差问题 → 好问题）

| 问题病灶 | 原始差问题 | 升级版好问题 | 底层原理 |
| :--- | :--- | :--- | :--- |
| **过于宽泛（求全）** | “你能给我讲讲大模型 RAG 吗？” | “在微调成本高的前提下，RAG 解决的核心痛点是什么？如果用图书管理员打比方，它最核心的 3 步流程是什么？” | 定坐标 + 费曼锚定 |
| **封闭死胡同** | “这个架构方案可行吗？” | “如果要让这个架构在 10 倍并发下出故障，您觉得最先扛不住的瓶颈会是哪一环？” | QFT 开放化 + 逆向思维 |
| **带偏见的伪装陈述** | “你难道不觉得微服务在早期都是过度设计吗？” | “在团队规模还比较小的时候，您当初是遇到什么具体痛点，才决定引入微服务的？” | 《谦逊的提问》纯粹好奇 |
| **被动伸手** | “我该怎么入门量化交易？” | “我理解量化交易的核心是‘用历史统计规律替代情绪决策’，这个理解对吗？如果我想先跑通最小闭环，必须先弄懂的前 3 个概念是什么？” | 抛砖引玉（假设驱动）+ 找抓手 |
| **缺乏边界感** | “A 和 B 哪个更好？” | “在什么具体业务约束下，选 A 会明显优于 B？又在什么临界点上必须切到 B？” | 边界探测法 |

## 二、QFT（问题形成技术）快速流程

当面对一个完全陌生的主题（Q-Focus）大脑一片空白时，可用 4 步破局：
1. **发散产题**：不评判好坏、不急着找答案，一口气写出所有冒出来的疑问（包括把陈述句改成问句）。
2. **分类改造**：标出哪些是**封闭问题**（是/否/单一事实），哪些是**开放问题**（需要解释机制/原因）；把关键封闭题改写成开放题，把太散的开放题收敛成可验证的封闭题。
3. **精选排序**：结合当前目标，只挑出 **最关键的 Top 3 问题** 作为第一轮行动抓手。
4. **行动闭环**：明确这 3 个问题分别用来**问 AI、查资料、还是请教专家**。

## 三、分场景即用型提问模板

### 1. 向专家 / 前辈请教（5 句黄金模板）
- **锚定纠错**：“我目前对 [X] 的粗浅理解是 [你的猜想]，在您实战经验里，这种理解最大的盲区是什么？”
- **反直觉追问**：“外界对 [X] 最常见的误解是什么？您自己也是踩过坑才意识到的吗？”
- **决策瞬间**：“回看您做过的 [某项目/决定]，当时最难权衡的两个选项是什么？最后是什么信号让您拍板的？”
- **失效边界**：“您觉得 [某方法/经验] 在什么情况下会完全失灵，千万不能照搬？”
- **极简路径**：“如果您现在重头学 [X]，您会直接跳过哪些浪费时间的东西，只死磕哪 2–3 件事？”

### 2. 研读论文 / 专业文章（SQ3R + 艾德勒四层模板）
- **读前（Survey → Question）**：只看标题、摘要、小标题和图表，问：“这篇文章试图推翻或改进什么旧做法？它最核心的创新点藏在哪个章节？”
- **读中（细节追踪）**：“作者定义的 [核心术语] 精确边界是什么？实验/论证的对照组合理吗？”
- **读后（批判与迁移）**：“如果把文章的结论应用到我的实际场景中，哪一个假设条件可能不满足？合上文章后，我能用 3 句话讲清它的逻辑主线吗？”

### 3. 批判性审视观点 / 方案（5 问体检表）
1. **前提**：这个结论成立，暗含了哪 2–3 个未被验证的前提假设？
2. **证据**：给出的数据或案例，是普遍规律还是极端个案（幸存者偏差）？
3. **因果**：这是真正的因果关系，还是仅仅同时发生的相关性？
4. **反面**：如果一个极其聪明的反对者来反驳这套说法，他最有力的 2 个论据会是什么？
5. **后果**：如果完全按这个建议执行 1 年，最可能出现的意外副作用是什么？
