# Question Craft（高质量提问生成与打磨术）

解决“面对专家不敢开口、面对长文不知从何读起、面对观点不知如何批判”的难题，把模糊的困惑转化为**高信息密度的精准问题清单**。

## 步骤 1：识别提问场景

根据用户意图选择对应工作流（若涉及多个场景，可组合使用）：

| 场景 | 典型需求 | 核心方法 |
| :--- | :--- | :--- |
| **场景 1：向人请教 / 访谈专家** | 要见前辈、专家、同行或做调研，想高效套取真实经验 | 谦逊的提问（Humble Inquiry）+ 抛砖引玉（假设驱动）+ QFT 优先级排序 |
| **场景 2：主动研读文章 / 论文 / 书籍** | 要啃一份陌生领域的文档、论文、报告或厚书 | KWL 激活 + 艾德勒四层追问 + SQ3R（先问后读） |
| **场景 3：批判性审问 / 观点体检** | 面对一篇热文、商业方案、AI 回答或权威结论，想识别漏洞与泡沫 | 《学会提问》假设与证据审计 + 苏格拉底追问 + 逆向压力测试 |
| **场景 4：问题诊断与改写** | 用户已有几个初步问题，但感觉太泛、太浅或容易招致敷衍回答 | QFT 封闭/开放互转 + 去预设偏见改写 |

> 如需详细的问题改写对照表与可直接套用的提问模板，按需读取 [templates.md](./references/templates.md)。

---

## 步骤 2：按场景生成与打磨问题

### 场景 1：向专家 / 前辈请教（谦逊 + 假设驱动）

1. **排除三类低效提问**：
   - 泛泛而谈型（“您能讲讲 X 吗？”→ 信息密度极低）；
   - 伪装陈述型（“您不觉得 X 其实没用吗？”→ 带有预设偏见，引发防备）；
   - 搜索引擎型（百度/AI 三秒能查到的基础定义）。
2. **产出分阶段提问清单（精选 5–7 题，按聊天气氛递进）**：
   - **破冰锚定（1–2 题）**：用**抛砖引玉**展示你做过功课（“我目前把 X 理解为……，这个理解在实战里偏差最大的地方在哪？”）。
   - **经验深挖（2–3 题）**：用**纯粹好奇的开放式提问**问决策瞬间、踩坑教训与反直觉细节（“当时是什么具体信号让您决定放弃方案 A 的？”）。
   - **边界与前瞻（1–2 题）**：问失效条件与未来判断（“如果是新手从零入行，最容易踩的隐蔽陷阱是什么？”）。
3. **标注“必问 Top 3”**：按 QFT 优先级原则标出时间紧张时绝对不能漏掉的 3 个核心问题。

---

### 场景 2：带着问题读长文 / 论文 / 书（KWL + 四层追问 + SQ3R）

在用户通读全文之前（或基于用户提供的文本/目录/摘要），先生成一份**阅读导航问题单**：

1. **KWL 热身（30 秒激活旧知识）**：
   - **K（已知）**：列出读前可锚定的 2–3 个相关常识；
   - **W（想知）**：把标题、小节名或核心主题转化为具体问题（SQ3R 的 *Survey → Question*）。
2. **艾德勒四层追问清单**：
   - **第一层（整体架构）**：作者到底在解决什么核心问题？全篇主线结论是什么？
   - **第二层（细节展开）**：作者用了哪些核心概念、方法、数据或案例来支撑结论？
   - **第三层（真伪评估）**：论证链条里哪一步最薄弱？有无未明说的前提或反例？
   - **第四层（与我何干）**：如果全篇都对，它如何改变我的认知、工作流或下一步行动？
3. **Recite（复述检验题）**：给出 2 个读完后可以合上材料自测的费曼检验题，确保真正吸收（填满 KWL 的 **L**）。

---

### 场景 3：批判性审问与观点体检（防盲信、破泡沫）

针对用户给出的一段观点、方案、文章或结论，从 **5 个审辩维度** 输出锋利的质询问题：

1. **概念澄清**：核心词汇有没有偷换概念、模糊定义或用情绪词替代事实？
2. **隐含假设**：这个结论必须依赖哪些“没说出口的前提”才成立？若前提松动会怎样？
3. **证据效力**：支撑它的数据/案例样本够吗？是否存在幸存者偏差、相关性当因果性？
4. **立场与激励**：提出这个观点的人处于什么位置？谁受益、谁承担风险？
5. **对立视角与逆向测试**：最强的反对派会怎么反驳（Steelmanning）？如果极端反面情况发生，哪一环最先崩溃？

---

### 场景 4：问题诊断与改写（QFT 打磨术）

当用户给出自己的原始问题时，按以下 3 步升级：
1. **诊断病灶**：指出原问题属于太宽泛、封闭死胡同、自带偏见还是问错层级。
2. **封闭 ↔ 开放转换**：展示该问题在**封闭式**（用于快速确认边界/假设）和**开放式**（用于激发深度洞察）下的不同写法。
3. **给出 2–3 个升级版问法**：分别适配“问 AI”和“问真人专家”两种语境，并简述为什么升级版能换回更高密度的回答。

---

## 步骤 3：输出规范

- 问题清单保持**精炼、可直接复制使用**，每个问题控制在 1–2 句话内，避免冗长说教。
- 明确标出 **Top 3 优先问题**（QFT 原则），防止问题太多导致选择困难。
- 若用户拿到问题清单后希望直接由 AI 逐题解答来学习该领域，可顺势衔接 `learn-by-questioning` 技能。
